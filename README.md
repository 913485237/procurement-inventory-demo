# Aether AI 原生制造业 ERP

面向客户与管理层演示的本地 AI ERP。它把 AI 作为受权限控制的“数字员工”，串联供应链风险分析、补货审批、出货、开票与审计。

## 快速启动

运行 [启动AI-ERP.bat](启动AI-ERP.bat)，系统会：

1. 初始化本地 SQLite 演示数据库；
2. 在 `http://127.0.0.1:8765` 启动服务；
3. 使用系统默认浏览器打开项目。

也可以在项目目录执行：

```powershell
python app.py --open
```

运行要求：Windows 与 Python 3.11 或更高版本。不需要安装任何第三方 Python 或前端依赖。

## 主要页面

- 经营总览：订单、交付、风险与审批指标。
- AI 指挥中心：自然语言指令、权限继承、执行计划和提供方降级。
- 供应链风险：原料、供应商、生产任务、订单和客户影响链。
- 业务工作台：采购、库存、订单、出货与发票。
- 审批中心：高风险动作人工批准或驳回。
- 审计与设置：查看完整操作链，配置外部 AI 或 Ollama。

## AI 降级顺序

系统按以下顺序选择能力：

1. 外部 OpenAI 兼容接口；
2. 本地 Ollama；
3. 内置规则引擎。

没有任何 AI 接口或本地模型时，规则引擎仍支持以下演示指令：

- `分析航空铝板缺料风险和影响订单`
- `生成航空铝板补货采购方案`
- `执行受影响订单的出货并开票`
- `我是谁，AI 继承了哪些权限`
- `查看经营总览`

### 配置外部 AI

使用管理员角色进入“审计与设置”，填写：

- OpenAI 兼容接口地址；
- 模型名称；
- API 密钥。

密钥只保存在本地 `config.json`，该文件已被 Git 忽略，接口不会向前端返回原始密钥。

### 配置 Ollama

在本机启动 Ollama 服务，在设置页填写服务地址和模型名称。默认地址为 `http://127.0.0.1:11434`，默认模型为 `qwen3:8b`。

## 演示角色

- 林澈：管理员
- 周岚：采购经理
- 陈宇：仓库主管
- 赵敏：销售经理
- 沈言：财务专员

AI 始终继承当前角色权限。可以切换到销售经理后尝试“生成补货方案”，观察安全网关如何阻止越权动作。

## 重置数据

使用管理员角色进入“审计与设置”，点击“重置演示数据”。系统只会重建 `data/erp_demo.db` 中的演示数据，不会修改源码或原视频。

也可以在下次启动前执行：

```powershell
python app.py --reset-data
```

## 测试

运行 [运行测试.bat](运行测试.bat)，或执行：

```powershell
python -m unittest discover -s tests -v
```

测试覆盖权限继承、AI 降级、缺料计算、审批事务、回滚和幂等保护。

## 项目结构

```text
backend/     数据库、权限、风险、ERP、AI 与审计
web/         本地浏览器界面
tests/       标准库 unittest 测试
scripts/     启动与测试脚本
docs/        设计和实施文档
app.py       HTTP 服务入口
```

详细客户演示步骤见 [五分钟演示脚本](docs/五分钟客户演示脚本.md)。
