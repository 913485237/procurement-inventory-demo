# 通知抽屉与个性化设置面板设计

## 背景

顶部通知按钮当前只有未读角标，没有打开行为。侧栏底部齿轮虽然复用了“审计与设置”页面跳转，但没有独立的个性化设置入口，用户点击后难以理解反馈。

本次改造让两个入口具有清晰、独立且可重复使用的交互：通知按钮打开通知抽屉，设置按钮打开轻量设置浮层。

## 目标

- 通知按钮可以反复打开和关闭右侧通知抽屉。
- 通知支持逐条展开详情、收起、标记已读和全部已读。
- 未读角标与通知状态同步，并在未读数为零时隐藏。
- 设置按钮打开小型个性化设置面板，调整结果即时生效。
- 设置仅在当前页面会话内有效，刷新页面后恢复默认值。
- 两个面板互斥，支持点击外部和按 `Escape` 关闭。

## 通知抽屉

### 布局

- 从页面右侧滑入，桌面宽度约 380px。
- 抽屉打开时显示半透明遮罩。
- 顶部包含“通知中心”、未读数量、“全部已读”和关闭按钮。
- 初始展示两条与演示业务一致的通知：
  1. 航空铝板库存低于安全线。
  2. 高优先级订单即将到达交付节点。

### 交互

- 点击通知按钮切换抽屉的打开与关闭状态。
- 点击单条通知时，在该条内部展开时间、影响范围、建议动作和“前往处理”按钮，并立即标记为已读。
- 再次点击已展开条目时收起详情。
- “全部已读”将所有通知改为已读状态。
- 点击“前往处理”关闭抽屉，并进入对应的供应链风险或业务工作台视图。
- 点击遮罩、关闭按钮或按 `Escape` 关闭抽屉。
- 未读角标始终根据未读通知数量计算；数量为零时隐藏。

## 个性化设置面板

### 布局

- 点击侧栏底部齿轮后，在齿轮右上方打开约 320px 的浮层。
- 浮层包含标题、设置分组和“恢复默认”按钮。
- 浮层不替代现有“审计与设置”业务页面；齿轮改为专用的个性化设置入口。

### 设置项

- 字体大小：小、标准、大。
- 界面风格：浅色、混合、深色。
- 紧凑布局：降低主要区域的间距与控件高度。
- 减少动画：关闭滑入、淡入和悬停位移动画。
- 高对比度：增强文字、边框和控件的明暗对比。
- 圆角大小：直角、标准、圆润。

### 交互与状态

- 所有设置通过根节点上的 CSS 类或数据属性即时应用。
- 设置状态仅保存在当前页面的 JavaScript 内存中，不写入后端、Cookie、`localStorage` 或 `sessionStorage`。
- 刷新页面后恢复项目默认值：标准字体、混合风格、标准间距、启用动画、标准对比度和标准圆角。
- “恢复默认”立即还原全部默认值。
- 点击齿轮可切换面板开关；点击面板外或按 `Escape` 关闭。

## 面板协调与可访问性

- 通知抽屉和设置浮层互斥；打开一个时自动关闭另一个。
- 按钮使用准确的 `aria-label`、`aria-expanded` 和 `aria-controls`。
- 面板通过 `aria-hidden` 表达可见状态。
- 可展开通知条目使用按钮结构，并同步 `aria-expanded`。
- 所有操作保留清晰的键盘焦点样式。
- 小屏幕下通知抽屉宽度不超过视口，设置面板在侧栏打开时保持可见。

## 实现边界

- 使用现有 HTML、CSS 和原生 JavaScript，不新增第三方依赖。
- 通知使用演示数据，不新增后端通知接口。
- 个性化设置不修改现有 AI 模型与降级策略配置。
- 不修改现有角色权限、业务流程或 SQLite 数据。

## 异常处理

- 找不到目标视图时，“前往处理”保持当前页面并显示错误提示。
- 重复点击打开、关闭、展开或收起操作必须保持幂等，不产生重复节点或事件监听。
- 面板关闭后保留当前会话中的通知已读状态和个性化设置状态。

## 验收与测试

1. 连续打开和关闭通知抽屉至少三次，均正常响应。
2. 逐条展开、收起通知后，详情与 `aria-expanded` 同步。
3. 阅读一条通知后角标从 2 变为 1；全部已读后角标隐藏。
4. “前往处理”可进入正确业务视图并关闭抽屉。
5. 设置面板可连续打开和关闭，且与通知抽屉互斥。
6. 每个字体、风格、圆角选项以及三个开关均即时改变页面表现。
7. “恢复默认”可一次性恢复所有默认状态。
8. 刷新页面后设置恢复默认，不进行任何持久化。
9. 点击外部和按 `Escape` 均能关闭当前面板。
10. 现有角色切换、业务导航、AI 设置和后端测试继续通过。
