# 采购与库存补货协同管理系统：运行说明

## 环境要求

- Windows 10/11；
- Python 3.11 或更高版本；
- 无需安装第三方 Python 包。

## 启动

双击 `启动AI-ERP.bat`。

也可以在解压目录执行：

```powershell
python app.py --open
```

系统默认访问地址为 `http://127.0.0.1:8765`。首次启动会自动创建 `data/erp_demo.db` 演示数据库。

## 推荐体验路径

1. 切换到“周岚 · 采购经理”；
2. 打开“供应链风险”；
3. 查看航空铝板库存缺口；
4. 选择 AI 建议或人工经验补货；
5. 提交采购审批；
6. 切换管理员完成审批并查看生成的采购单。

没有外部 AI 接口或本地模型时，系统会自动使用内置规则引擎，不影响主流程体验。

## 数据说明

项目仅使用虚构演示数据。若需要恢复初始数据，可停止程序后删除 `data/erp_demo.db`，再次启动即可重新生成。
