# AI 原生制造业 ERP 实施计划

## 目标

在不依赖第三方 Python 或前端包的前提下，交付可在 Windows 本地启动、可离线演示、可接 OpenAI 兼容接口或 Ollama 的制造业 AI ERP。

## 实施顺序

1. 创建项目目录、配置示例和忽略规则。
2. 实现 SQLite 表结构、演示数据、重置和连接管理。
3. 实现角色权限、审计、幂等、风险分析、审批和 ERP 事务动作。
4. 实现 AI 动作注册表、规则意图解析、OpenAI/Ollama 适配和自动降级。
5. 实现 Python 标准库 HTTP API 与静态文件服务。
6. 实现单页前端：经营总览、AI 指挥中心、风险中心、业务工作台、审批中心、审计设置。
7. 增加 Windows 启动/测试脚本、中文 README 和五分钟演示说明。
8. 先运行单个规则引擎测试验证最小链路，再运行完整单元测试。
9. 启动本地服务，依次验证健康检查、总览、风险、AI 指令、审批执行和审计接口。
10. 检查 Git 差异并提交项目源码；视频保持未跟踪且不修改。

## 文件边界

- `app.py`：程序入口与 HTTP 路由。
- `backend/db.py`：数据库结构、种子数据和连接。
- `backend/auth.py`：角色权限判断。
- `backend/risk.py`：缺料与影响链计算。
- `backend/erp.py`：审批、出货、开票等事务动作。
- `backend/ai.py`：AI 提供方、降级和规则引擎。
- `backend/audit.py`：结构化审计写入与查询。
- `web/`：浏览器端页面、样式与交互。
- `tests/`：标准库 `unittest` 测试。
- `scripts/`：启动与测试脚本。

## 验证门禁

- 最小测试：仅运行规则引擎解析与风险查询测试。
- 全量测试：运行 `unittest discover`。
- 冒烟测试：使用临时数据库和非默认端口启动服务，验证核心 API，再关闭进程。
- 人工检查：确认页面无占位内容、无控制台错误、离线模式状态明确。
