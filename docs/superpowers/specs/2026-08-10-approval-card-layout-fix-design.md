# 审批卡片布局错位修复设计

## 问题

审批卡片使用三列 CSS 网格：左侧状态色条、中间主内容、右侧操作或处理状态。渲染模板同时输出了一个无内容的空 `div`，与 `::before` 状态色条一起占用了两个网格位置，导致主内容进入第三列，操作区换行到下一行。

## 修复方案

- 删除审批卡片模板中紧跟 `article` 开始标签的多余空 `div`。
- 保留 `::before` 作为左侧状态色条。
- 保留现有三列布局 `6px 1fr auto`：状态条、主内容、操作区。
- 保留现有小屏幕规则：卡片变为两列，操作区位于主内容下方。
- 不修改审批数据、权限、状态判断和操作逻辑。

## 验收标准

1. 桌面宽度下，标题、原因和参数位于卡片中间主区域。
2. 审批按钮或“已批准并执行”等状态固定在卡片右侧，与主内容同一行。
3. 左侧状态色条完整覆盖卡片高度。
4. 小屏幕下操作区域进入内容下方，不发生文字重叠或溢出。
5. 待审批、已批准、已驳回三种状态均保持正确布局。
6. 个性化字体、主题、紧凑布局和圆角设置不改变卡片网格顺序。
7. 现有后端测试和审批工作流继续通过。
