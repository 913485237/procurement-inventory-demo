# 仪表盘指标与趋势下钻交互设计

## 背景

经营驾驶舱的四张核心指标卡和“订单与交付表现”趋势图目前只负责展示数据，无法进入对应业务模块，也不能查看某个月份的经营摘要。用户需要从仪表盘直接下钻，减少在侧边导航和业务标签之间反复查找的操作。

## 目标

- 四张指标卡整卡可点击，并跳转到对应业务模块。
- 趋势图的柱体和月份文字可打开该月经营详情。
- 月度详情可继续进入销售订单或出货单列表。
- 支持鼠标、键盘、浅色主题、深色主题和窄屏布局。
- 沿用现有单页导航、业务标签与弹窗样式，不新增页面路由、后端接口或外部依赖。

## 方案选择

采用“指标卡直接跳转、趋势图先查看月度详情”的混合方案。

该方案比“全部直接跳转”保留了趋势数据的月度上下文；比“全部打开弹窗”更适合四张含义明确的指标卡，也减少不必要的操作层级。当前趋势数据是聚合指标而非逐笔业务记录，因此月度弹窗只展示可靠的汇总数据，不伪造月份筛选结果。

## 指标卡导航映射

| 指标卡 | 目标位置 | 目标状态 |
|---|---|---|
| 在手订单金额 | 业务工作台 | 激活“销售订单”标签 |
| 供应链风险 | 供应链风险 | 显示风险列表 |
| 待审批任务 | 审批中心 | 显示待审批任务 |
| 本月准时交付率 | 业务工作台 | 激活“出货单”标签 |

点击后调用现有视图切换逻辑。进入业务工作台时，先更新当前业务类型和标签激活状态，再加载对应列表；不复制或绕过现有加载流程。

## 指标卡交互

- 整张卡片是一个可操作区域，保留内部指标、图标和趋势装饰的现有布局。
- 鼠标悬停时通过边框、阴影和轻微位移表达可点击性；按下时提供即时反馈。
- 卡片具备按钮语义和说明性标签，支持 `Enter` 与空格键触发。
- 键盘聚焦时显示清晰焦点环；浅色和深色主题均满足可辨识要求。
- 卡片装饰元素不单独获得焦点，避免重复导航入口。

## 趋势图交互

- 每个月份的蓝柱、绿柱与月份文字组成一个统一点击区域。
- 点击或键盘触发后打开“月度经营详情”弹窗。
- 蓝柱解释为“订单指数”，绿柱解释为“准时交付率”，保持与现有聚合数据口径一致。
- 悬停和聚焦时同时强调该月的两根柱体与月份标签，避免用户误解为只能查看单项指标。
- 图表保留现有视觉比例，不引入第三方图表库。

## 月度经营详情

弹窗显示以下内容：

- 当前月份。
- 订单指数。
- 准时交付率。
- 两项指标相较上月的变化值；首月显示“暂无上月数据”。
- “查看销售订单”按钮，进入业务工作台的销售订单标签。
- “查看出货记录”按钮，进入业务工作台的出货单标签。

弹窗沿用现有遮罩、圆角、主题变量、滚动限制和关闭方式。支持顶部关闭按钮、底部关闭按钮、点击遮罩和 `Escape`；关闭后焦点返回触发它的月份。

## 数据流与边界

1. 仪表盘继续通过现有 `/api/dashboard` 获取指标和趋势数据。
2. 指标卡只读取现有指标值并调用本地视图切换函数，不产生新请求。
3. 趋势图渲染时把月份、订单指数、交付率和数组位置绑定到月份交互单元。
4. 打开详情时使用当前已加载趋势数据，并根据数组中的前一项计算环比差值。
5. 从详情跳转时先关闭弹窗，再切换视图和业务标签，避免遮罩残留。

本次不提供按月份过滤实际订单或出货记录，因为现有趋势数据没有逐笔记录映射。详情按钮进入完整业务列表，不暗示已经应用月份筛选。

## 异常与空状态

- 某个趋势值缺失时显示“暂无数据”，不渲染 `undefined`、`null` 或 `NaN`。
- 缺少上月数据时显示“暂无上月数据”，不计算虚假环比。
- 目标模块因权限或加载错误无法打开时，保留当前可用页面并沿用现有错误提示机制。
- 快速连续点击不同月份时始终以最后一次点击的数据为准。
- 视图切换、主题切换和窗口缩放不得留下已关闭弹窗的遮罩或滚动锁定状态。

## 响应式与主题

- 新增样式使用现有主题变量，浅色和深色界面保持统一。
- 窄屏下详情摘要由双列或多列收拢为单列，操作按钮可纵向排列。
- 图表点击区域不得造成页面横向溢出；月份标签保持可见。
- 减少动态效果偏好开启时，取消非必要的位移与过渡动画。

## 验收与测试

1. 四张指标卡可通过鼠标、`Enter` 和空格键进入正确模块或业务标签。
2. 六个月份的柱体和月份文字均可打开与该月对应的详情。
3. 月度详情正确显示订单指数、准时交付率和环比变化，首月正确显示无上月数据。
4. 两个详情入口分别进入销售订单和出货单，并正确关闭弹窗。
5. 弹窗四种关闭方式有效，关闭后焦点返回原月份。
6. 数据缺失时显示明确空状态，页面其他功能不受影响。
7. 浅色、深色、桌面宽度和窄屏宽度下无文字错位或横向溢出。
8. 现有订单详情、业务详情、风险、审批、通知、设置、角色切换及 AI 本地降级流程继续通过。
9. 验证顺序遵循项目要求：先执行语法检查和定向小规模测试，再执行完整单元测试、接口冒烟测试与浏览器交互验证。

## 非目标

- 不新增独立详情页面或 URL 路由。
- 不增加按月筛选销售订单、出货记录的后端查询能力。
- 不修改仪表盘指标口径或趋势数据生成方式。
- 不改动业务数据、角色权限、审批状态或审计记录。
